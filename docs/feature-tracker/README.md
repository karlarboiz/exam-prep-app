# Feature tracker

Living **Done / Pending** status for product work, by category.

- Use this folder to see what is built, what is open, and what to pick up next.
- When you finish an item, set its status to **Done** and add a short note if useful.
- When you discover new work, add a **Pending** row in the matching category file (or create a new category file and link it here).

Start-task process (order of work, checklists, smoke paths): [PRE-IMPLEMENTATION.md](../PRE-IMPLEMENTATION.md)  
How a capability works (implementation docs): [features/](../features/)
