# User dashboard

**Path:** `WEB-INF/jsp/user/dashboard.jsp`  
**Route:** `/user/dashboard`  
**Servlet:** `DashboardServlet`

Available exams (`.exam-grid` / `.exam-card`) and subjects sit in `.grid-2`. Recent attempts stay full width below. CTA opens exam start options (`/user/exam?examId=`) so the examinee can choose when answers are revealed.
