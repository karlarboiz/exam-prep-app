# Admin exams page

**Path:** `WEB-INF/jsp/admin/exams.jsp`  
**Route:** `/admin/exams`  
**Feature:** [admin-exams](../../features/admin-exams/overview.md)

Exam CRUD with subject select, duration, active checkbox, **diagnostic** checkbox, questions-per-subject (when diagnostic), and a scrollable ordered question list for practice exams (checkboxes plus Up/Down; hidden when diagnostic is checked).
