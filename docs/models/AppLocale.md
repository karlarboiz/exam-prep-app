# AppLocale

**Source:** `com.examprep.model.AppLocale`

UI language for chrome and messages.

| Value | Code | Notes |
|-------|------|-------|
| TL | `tl` | Tagalog — default |
| EN | `en` | English |

`fromCode` also accepts `fil` as Tagalog. Date formatting uses Filipino CLDR (`fil`) when Tagalog is active so month names resolve.
