# BehaviorEventType

**Source:** `com.examprep.model.BehaviorEventType` (enum)

| Value | Meaning |
|-------|---------|
| LEAVE | Examinee left the exam page (tab hidden, window blur, header nav, or tab close) |
| RETURN | Examinee came back (tab visible / focus, or resumed the attempt URL) |

`fromString(String)` accepts case-insensitive names.
